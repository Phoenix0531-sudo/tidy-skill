## 🎯 Core Features

* 🔍 **Artifact Intent Check**: Forces the Agent to self-audit before creating any file: Is this file necessary? Why is a chat reply not enough?
* 🚫 **Root Directory Anti-Pollution**: Automatically intercepts unowned temporary Markdown files like `plan.md` and `todo.md` from entering the project root.
* 💯 **Repo Hygiene Scoring**: Deeply diagnoses the cleanliness of your repository files based on six major dimensions (0–100 points).
* 📂 **Workspace Batch Audit**: Scans and generates summary reports of Agent trash artifacts across multiple repositories with one click.
* 🧹 **Conservative Safe Cleanup**: Defaults to DryRun mode preview; only cleans up expired temporary files and reports, never touching your formal documents.

Running `score-repo-hygiene.ps1` gives an intuitive scoring and recommendation report:

```

Dimension Breakdown:
- Root cleanliness       : 18 / 25  (Found plan.md, todo.md)
- Artifact placement     : 15 / 20  (Temporary files not isolated)
- Protected docs clarity : 12 / 15
- Git hygiene            : 11 / 15
- Agent state isolation  : 15 / 15
- Cleanup readiness      : 0 / 10
```

### 2. Artifact Intent Check Process
After integrating Tidy Skill into your project, the Agent must run the following self-audit before writing any file:
```
Artifact Intent Check
─────────────────────
1. User requested a file?           yes / no
2. Purpose: Record multi-module refactoring steps
3. Reader: Agent of the current session
4. Expected lifetime:               Session
5. Destination path:                .agent_tmp/refactor_steps.md
6. Why a chat response is not enough: Information is too large to fit, needs to be continuously referenced as context
7. Class:                           Class C (Temporary working artifact)
8. Should this be in .gitignore?    Yes (already in .gitignore)
```
If any field cannot be answered confidently, **do not create the file.**

## 📦 Installation & Configuration

### 1. Install as a Skill
If you are using an AI platform compatible with the Agent Skills protocol, you can directly link or copy this project:
```bash
# Link this project as a global Skill
ln -s /path/to/tidy-skill ~/.your-agent/skills/tidy-skill

# Or copy directly
cp -r /path/to/tidy-skill ~/.your-agent/skills/tidy-skill
```

### 2. Manually Integrate into Various Development Environments
You can directly copy the corresponding templates into your project:

#### 🤖 Claude Code
```bash
cp templates/CLAUDE.md /path/to/your/project/CLAUDE.md
```

#### 🎨 Cursor
```bash
# Copy cursor rule file
cp templates/cursor-rule.mdc /path/to/your/project/.cursor/rules/agent-tidy.mdc
```

#### 🌐 General Agents (like Codex, etc.)
```bash
cp templates/AGENTS.md /path/to/your/project/AGENTS.md
```

#### 📄 Full Governance Policy Document
```bash
cp templates/artifact-governance-policy.md /path/to/your/project/docs/
```

### 3. Project Best Practices
It is recommended to add the following configuration to your project `.gitignore` to completely isolate temporary files generated by the Agent from version control:
```gitignore
.agent_tmp/
.agent_reports/
```

The recommended project structure is as follows:
```
project/
├─ AGENTS.md            # Agent Self-Discipline Code (Class A)
├─ .agent_tmp/          # Temporary Agent Files (Class C - auto-cleanable)
├─ .agent_reports/      # User-requested Reports (Class B - auto-cleanable in 30 days)
├─ README.md            # Formal Document (Class A - never touched)
├─ docs/                # Formal Document Directory (Class A - never touched)
└─ src/
```

## 🛡️ Artifact Safety Boundaries

All auditing and cleaning operations come with extremely high safety guarantees:
1. **Read-only Audit**: The audit script only scans file metadata (name, size, modification time) and does not read or upload file contents.
2. **Default DryRun**: The cleanup script defaults to a preview mode and will not delete any files without confirmation.
3. **Root Safety**: Suspicious files in the root directory are only reported and not automatically cleaned (unless the `-ConfirmClean` parameter is used).
4. **Protected List (Never Deleted)**:
   - Core project files: `README.md`, `LICENSE`, `CHANGELOG.md`, etc.
   - All documents under `docs/`.
   - Any files tracked by Git.
   - Source code (`src/`, `lib/`) and tool state directories (`.claude/`, `.cursor/`, `.vscode/`).

## 🛠️ Script Description

This project provides zero-dependency PowerShell scripts that can run natively on Windows (built-in) and macOS/Linux (running pwsh):

| Script | Purpose | Safety |
|---|---|---|
| `audit-agent-artifacts.ps1` | Read-only audit of Agent artifacts in a single repo | Read-only, no modifications |
| `score-repo-hygiene.ps1` | Score repository cleanliness across 6 dimensions (0-100) | Read-only |
| `audit-workspace-hygiene.ps1` | Scan multiple Git repositories in a workspace | Read-only, explicit root path required |
| `clean-agent-artifacts.ps1` | Clean up expired temporary files and reports | Defaults to DryRun |
| `clean-agent-artifacts.bat` | One-click cleanup utility for Windows | Defaults to DryRun |
